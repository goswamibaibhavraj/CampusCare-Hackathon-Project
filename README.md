# CampusCare — LPU Student Healthcare Support

CampusCare is a student project focused on making common healthcare information and support options easier for LPU students to find in one place.

The project was developed with a team during a campus hackathon. It is a prototype, not an official LPU medical service.

## What the prototype includes

- Student login and profile screens
- A campus doctor directory and appointment flow
- A consultation interface
- Prescription and medicine-routine screens
- Campus healthcare information
- A student wellbeing section
- A health assistant interface
- An emergency support screen

Some screens and workflows are demonstrations. They do not replace medical advice, real appointment systems, emergency services, or official university facilities.

## Technology used

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase

## Run locally

You will need Node.js and npm.

```bash
git clone https://github.com/goswamibaibhavraj/CampusCare.git
cd CampusCare
npm install
npm run dev
```

Open the local address printed by Vite in your terminal.

## Project note

This project was built for learning and demonstration. Do not enter real medical or other sensitive personal information into the prototype.
